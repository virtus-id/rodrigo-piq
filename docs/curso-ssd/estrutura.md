# Servidor Sem Dívidas (SSD) — estrutura do curso

O SSD é o produto de entrada; o PIQ é o upsell. Estrutura transcrita do material enviado pelo responsável do produto.
As legendas de cada aula estão em [legendas/](legendas/) (`aula-NN.vtt`, `aula-10-1.vtt`, `aula-10-2.vtt`, `bonus-*.vtt`).

> **Regra de uso:** toda referência ao curso deve vir **apenas** deste material (estrutura + legendas). Nada de fonte externa. Se o tema não está nas legendas, não há referência a fazer.
