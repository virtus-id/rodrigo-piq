# `specs/` — Especificações

Artefatos da fase de **descoberta e especificação**. Uma feature por slug:

- `<slug>.discovery.md` — análise do problema (`/sdd:discovery`)
- `<slug>.spec.md` — especificação do produto (`/sdd:spec`)

Estrutura obrigatória em [`templates/spec.template.md`](../templates/spec.template.md).

> A spec é a **fonte única da verdade**. Mudou o que o produto faz? Atualize a
> spec primeiro, depois plano, tarefas e código. Nunca o contrário.
